# 小雅视频连播助手

面向武汉理工大学小雅平台的浏览器用户脚本，支持视频连播、课程资料浏览、播放进度恢复，以及按课程保存今日学习时长。

**当前版本：1.0.2** · [脚本文件](./xiaoya-video.user.js) · [脚本猫发布页][scriptcat-release] · [使用说明](./使用说明.md) · [更新记录](./CHANGELOG.md)

## 安装与更新

1. 安装并启用 ScriptCat（脚本猫）或 Tampermonkey。
2. [前往脚本猫安装][scriptcat-release]；如需使用 GitHub 当前版本，可下载 [1.0.2 脚本](https://github.com/bbx88/xiaoya-learning-helper/releases/tag/v1.0.2)，或复制仓库中的 [完整脚本](./xiaoya-video.user.js) 到管理器。
3. 登录小雅，刷新课程页面，点击蓝色书本按钮展开面板。

已有旧版时，编辑原脚本，用新版全部代码替换并保存，再刷新课程页面。保留一个启用的版本，面板底部应显示 **v1.0.2**。保存编辑器不会替换已经运行的旧页面代码。

## 功能

| 功能 | 行为 |
| --- | --- |
| 单项／连续学习 | 首页切换；单项结束后停止，连续模式按课程目录顺序继续 |
| 自选学习队列 | 勾选“视频／其他资料”，学习范围选择“未完成／全部”，实时生效 |
| 视频连播 | 视频自然结束后等待 5 秒，再切换下一项；最后一项后停止 |
| 播放位置记忆 | 按账号、课程和视频保存进度；课程概览可“继续上次学习” |
| 非视频资料浏览 | PPT、PDF 等课程文件可加入队列，不要求都有自主观看标记 |
| 文件预览确认 | 学习中自动确认当前文件的预览提示，等待确认和加载时不计时 |
| 自主观看任务完成 | 非视频自主观看任务达到计划时间后点击平台“完成任务”，确认成功后再切换 |
| 停留时间设置 | 初始 2 分钟；用户全局默认跨课程共用，单项可单独设置 |
| 本次／今日时长 | 本地累计有效学习时间；今日按账号、课程和上海日期保存 |
| 完成状态 | 区分任务、视频观看记录和普通资料；确认全部完成后显示祝贺提示 |
| 资料列表 | 搜索、完成状态筛选、定位当前项、点击跳转和相邻资料切换 |
| 后台继续 | 恢复平台因页面隐藏而暂停的视频，处理“继续学习”弹窗 |
| 可移动面板 | 整个面板可滚动，课程名称行提供上下滚动和收起按钮 |

## 使用

1. 进入课程，在“学习”页选择单项或连续学习。
2. 勾选“视频／其他资料”，连续模式选择“未完成”或“全部”。
3. 点击开始；同一按钮可暂停、继续，右侧“停止”结束本次运行。
4. 停留时间、静音和后台继续在“设置”页调整，修改后自动保存。
5. 在“全部”页查看、搜索或手动选择资料；搜索和列表筛选不改变学习队列。

### 学习范围

**默认“未完成”**：跳过平台已确认完成的任务或视频，未知状态仍保留。普通资料不属于待完成任务，需要选择“全部”才会自动浏览。

**“全部”**：按所选类型浏览全部资料，包含已完成任务和普通课件，按顺序到最后一项停止，不循环。

“上一项／下一项”的名称和点击目标也跟随当前学习队列：连续模式选“未完成”时跳过已完成项目和普通资料，选“全部”时按所选资料目录相邻顺序切换。单项模式按所选资料目录切换；列表搜索和显示筛选不影响这些按钮。

选择会按账号和课程保存，修改立即生效。切换为“未完成”时，会跳过已完成的当前项；确认所选任务全部完成后，任务卡片显示“恭喜你，已经学完啦！”。只有普通资料的课程不误报完成。

界面只分“视频／其他资料”，PPT、PDF 等统一归入其他资料。有效任务标识才查询任务完成状态；没有任务标识的普通文件显示“普通资料”，真实接口失败仍显示“检测失败”。

### 停留时间

- 范围为 **2～1440 的整数分钟数**，初始 2 分钟。
- “全局默认停留”按当前用户保存，各课程共用；其他标签页的修改会同步。
- “本项停留”按账号、课程和资料单独保存，优先于全局默认；留空或点击“使用全局默认”恢复继承。
- 修改时间保留本页已停留进度；刷新或重新进入资料后，该资料的停留进度重新计时。
- 等待文件确认、加载、预览失败、暂停或弹窗阻塞时不累计有效停留。
- 非视频自主观看任务在计划时间达到后，通过当前资料的“点我完成任务”按钮提交，平台确认完成才切换；单项模式确认后停止。平台提供更长最低观看时间时，采用两者中较长的时间。
- 完成按钮缺失、平台拒绝或 30 秒内未确认成功时，保留当前任务并提示处理。普通资料仍按计划停留后切换。

### 三种时长

| 显示 | 口径与保存 |
| --- | --- |
| 本次学习时长 | 助手学习中实际视频播放和有效资料停留；暂停、切换资料、刷新后延续，停止或流程结束后下次开始重置 |
| 今日学习时长 | 同一账号、同一课程在上海日期下的本地累计；关闭重开保留，跨午夜按日期分配 |
| 已学习时长 | 从平台读取的历史统计，按平台次日更新的数据展示 |

本次与今日时长不计入暂停助手后单独操作播放器的时间；视频按实际耗时累计，倍速和拖动进度不会把跳过的媒体时长加进去。多个标签页各自有效学习的时间会相加。

本地累计不等于平台已计入的学时。任务是否完成、学习时长是否入账，以平台“我的学情”和任务记录为准。脚本操作页面已有播放器、读取任务记录，并通过页面按钮完成非视频自主观看任务，不直接提交学习时长或作业。

### 面板操作

顶部为课程名称及操作按钮，下面是“学习／全部／设置”。课程、选项、任务卡片和底部内容共用一条滚动区域，支持滚轮、触屏及上下箭头。

拖动课程名称或蓝色书本按钮移动位置。面板向下到最小高度后停止下移，小圆圈仍可移动；最小高度按面板顶部到播放按钮底部计算。按 `Esc` 收起，切换页签不暂停学习。

## 数据与缓存

所有配置和缓存均位于当前浏览器，登录令牌不写入缓存。

| 内容 | 范围或期限 |
| --- | --- |
| 全局默认停留 | 当前账号，跨课程共用 |
| 模式、资料类型、学习范围、单项停留 | 当前账号和课程 |
| 上次视频及各视频位置 | 当前账号、课程和视频；播放约每 5 秒及关键操作时保存 |
| 本次时长 | 当前标签页会话，刷新可延续 |
| 今日时长 | 当前账号、课程和上海日期，持久保存 |
| 静音、后台继续、悬浮位置 | 浏览器通用偏好 |
| 课程目录／完成状态／平台历史时长 | 分别缓存 10 分钟／30 秒／15 分钟 |

“全部”页的刷新按钮可重新检测目录、完成状态和平台历史时长，不清除播放位置或今日累计。清理网站数据会删除本地记录；更换浏览器或设备不会同步。

## 适用范围与已知限制

适配 `https://whut.ai-augmented.com/*` 和 `https://infra.ai-augmented.com/app/auth/*`。其他学校或域名未验证。

- 浏览器阻止自动播放时，手动点击一次页面的视频播放按钮。
- 在播放标签页内离开具体资料、进入作业或学情等页面，会停止本次运行。
- 电脑休眠、浏览器冻结标签页或网络中断时，播放和切换可能暂停或延迟。
- 页面结构或接口变化可能需要重新适配；反馈请提供版本、浏览器、管理器及复现步骤。

1.0.2 的本地检查覆盖 139 项用例。该版本没有在已登录的真实课程中完成全流程验收，不保证平台一定累计时长。后续可增强真实平台兼容性验证、缓存清理和跨设备同步；这些不属于当前版本的功能承诺。

## 开发与验证

单文件 JavaScript，无构建步骤。测试使用 Node.js 24 和锁定的 jsdom 依赖。

```sh
npm ci --prefix .tools
node --check xiaoya-video.user.js
node --test tests/verify.cjs tests/playback-memory.cjs tests/presentation-panel.cjs tests/queue-options.cjs tests/preview-confirmation.cjs tests/resource-status.cjs tests/user-defaults.cjs tests/session-duration.cjs tests/task-completion.cjs tests/queue-neighbors.cjs
git diff --check
```

测试使用模拟课程、播放器、时间和只读 GET 接口，不连接真实学习账号。覆盖登录与课程切换、播放恢复、队列、预览确认、普通资料分类、面板布局、默认时间迁移、本次／今日时长以及自主观看任务的完成与跳转、队列相邻资源导航。

`node tests/preview.cjs` 生成静态布局预览。`node tests/navigation.cjs` 是独立的 Chrome 本地模拟导航检查，需自行配置浏览器；未纳入本次 1.0.2 回归结果。仓库旧截图仅保留为历史素材，当前界面以脚本和静态预览为准。
