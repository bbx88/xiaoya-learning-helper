# 平台适配与历史核对记录

以下内容记录 2026-10-28 的公开前端核对结果，作为实现来源与维护背景，不代表发布当日重新验证了平台，也不随前端升级自动更新。当前使用方式与限制见 [使用说明](../使用说明.md)。

## 已下载脚本的检查结果

- `小雅做做做.user.js`，版本 1.3.6.1。`LearnRecorder` 使用 30 秒定时器，直接向 `/api/jx-iresource/learnLength/learnRecord` 提交带签名的学习记录；它没有监听视频结束并切换下一条，也没有处理未操作弹窗。页面路由变化时会停止记录器。另外还有直接调用 `finishActivity` 的任务提交功能，与正常视频播放不同。
- `小雅答答答.user.js`，版本 2.10.13。主要处理题目、资料和 AI 功能；与视频有关的代码主要用于获取音视频地址、资料预览和语音识别。未找到课程视频自动连播或“继续学习”弹窗处理。

新的脚本独立运行，读取课程目录并操作页面现有播放器。使用新脚本时，“做做做”的“学习时长记录”和任务提交功能保持关闭，便于确认平台正常播放的记录效果。

## 网站当前实现

2026-10-28 检查了网站公开提供的前端文件，未读取浏览器里的登录信息，也未执行课程提交。

- 入口：`https://whut.ai-augmented.com/app/jx-web/`
- 业务代码：`https://whut.ai-augmented.com/app/jx-web/js/index-7GZ1ILTx.js`
- 中文文案：`https://whut.ai-augmented.com/app/jx-web/js/zh-BOROkj3I.js`
- `learningRecorderSaga`：生产配置的未操作阈值为 1 小时，定时检查有间隔，所以弹窗出现时间不精确到整点。触发后暂停音视频，等待“继续学习”确认，再重置最近操作时间。
- 当前中文提示为：“截至{{current_time}}，长时间未操作，已停止记录学习时长，点击继续。”按钮文字为“继续学习”。
- `stopMediaWhenHidden()` 注册 `visibilitychange` 事件；`document.hidden` 为真时调用 `stopAllMedia()`，主动暂停全部音视频。新版在捕获阶段保留视频原本是否正在播放，针对这一暂停进行恢复。
- 播放器使用阿里云 Aliplayer；视频播放进度与课程学习时长使用不同的记录逻辑。视频结束时有 `complete` 事件记录，不能仅凭某个时长接口成功判断视频任务完成。
- 课程目录使用 GET `/api/jx-iresource/resource/queryCourseResources/v2?group_id=课程ID`；页面目录排序支持 `sort_position`。
- 课程名称使用 GET `/api/jx-iresource/group/queryGroup/课程ID`，读取 `name`；登录信息使用 GET `/api/jx-auth/oauth2/info` 的 `info.id`，HTTP 401 与网络故障分开处理。
- 任务完成状态使用 GET `/api/jx-iresource/resource/task/studentFinishInfo/v2`，传入 `group_id`、`node_id`、`task_id`，以 `finished` 判断任务完成。
- 自主观看记录使用 GET `/api/jx-iresource/vod/duration/引用资源ID`，根据 `duration` 与 `watched_duration` 计算观看进度，不使用 `played` 或本地播放结束事件推断完成。
- 历史学习时长使用 GET `/api/jx-stat/ads/duration/user?group_id=课程ID&user_id=当前用户ID&client_type=3&unit=1`，读取 `total_duration`（分钟）。当前用户 ID 取自 `/api/jx-auth/oauth2/info` 的 `data.info.id`。此接口与平台“学习时长”统计页一致，数据为次日更新。
- 视频链接形式为 `/app/jx-web/mycourse/课程ID/resource/父目录ID/资源ID`。

平台代码参考副本和历史版本可在本地 `reference/` 中保留，不随仓库发布；回归测试使用 `tests/platform-visibility.js` 中的页面隐藏处理片段。原有两个脚本没有被修改。
